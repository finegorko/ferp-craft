# FERP — Crafting Dashboard (WoW Forever)

Personal World of Warcraft addon showcase for the **FERP Crafting Dashboard** module on WoW Forever — tracking learned and unlearned recipes, reagent costs, and acquisition sources (trainers, vendors, Merchant's Favor, reputation, quests, and drops).

## Data Source & Attribution

Recipe metadata, acquisition sources, and direct item/spell links are powered by **[ForeverDB.net](https://foreverdb.net)**.
